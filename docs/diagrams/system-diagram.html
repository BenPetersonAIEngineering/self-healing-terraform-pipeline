Terraform Self-Healer — Pipeline Architecture

GitHub PR CI failure → scoped agent pipeline → confidence-gated commit → re-verified fix

Trigger & drive

  • • A PR's `terraform-demo.yml` run fails
  • • `self-heal.yml` fires on that `workflow_run`
  • • `healer-run-pr` resolves the PR into a `LiveCase`
  • • `live_orchestrator` runs the retry loop, capped at 3 attempts

Scoped agent pipeline

  • • Watcher structures the error, no repo access
  • • Analyzer names the exact files to change
  • • Coder's tool access is restricted to only those paths
  • • Confidence-check makes the real LLM COMMIT/WITHHOLD call

Commit, verify, report

  • • COMMIT pushes the fix directly onto the PR branch
  • • The push re-triggers CI; `ci_wait` polls the new run
  • • Success posts a comment with score, diff, and CI outcome
  • • WITHHOLD or CI failure loops back if attempts remain
